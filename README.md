# DADA2 Metabarcoding workflow using the University of Bristol ACRC BluePebble HPC

## 1) About, credits and other information

This workflow is largely based on Benjiman Callahan's DADA2 tutorial (v.1.8), available on the DADA2 GitHub page. It also draws heavily on GitHub workflow developed and maintained by Graeme Fox and Kathryn Maher (University of Sheffield), and expanded by the present contributor, for use on the University of Sheffield's HPCs. 

Here, the workflow is adapted for use on the University of Bristol ACRC's BluePebble HPC. With appropriate modfications, this should be transferable to any Linux/GNU-based HPC system (but your mileage may vary).

## 2) Get started on the HPC

You will need to have access to BluePebble or to ??? to use this workflow. If you are already set up, you can follow on below. If you need to get HPC access, please follow the instructions [here]().

If you are working on campus (i.e., logged in to Eduroam or on a hard connection), you can skip the next paragraph and log in to the HPC following the instructions further below.

If you are working off campus, you log in as below, but will need to log on to the VPN first. At first use, you will need to install and set up the VPN (F5 Access) from the University of Bristol Self Service portal. Instructions and guidance are available [here](). Once set up and all subsequent use, you should be able to log in to the VPN by launching F5 Access, which will open the familiar web page for you to log in, and you will need to 2FA (two-factor authenticate) with Microsoft Authenticator.
